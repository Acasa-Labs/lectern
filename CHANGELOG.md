# Changelog

## Unreleased

- Software updates through Sparkle: Lectern asks on its second launch whether to check automatically, and the Lectern menu has Check for Updates. Updates must be signed with Lectern's EdDSA key.

## 1.0.0 (2026-11-03)

The first public release.

- Editor with syntax highlighting, bracket matching, occurrence highlights, a minimap and word wrap.
- Markdown preview with Mermaid diagrams, and a JSON tree viewer.
- Folder sidebar, tabs (pin, colour, rename, bookmark), Quick Open, Find in Folder, and session restore.
- Source Control: stage, discard, commit, amend, fetch, pull, push, branches, stashes, plus history and diffs.
- Terminal and SSH tabs.
